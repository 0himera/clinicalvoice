# Повторная проверка zer0days — 19 октября 2026

После исправлений: **33/36 пройдены, 2 частично, 1 конфликт ожиданий, 0 провалов**. Все пять критических тестов пройдены. [Исходный прогон](test-plan-zer0days-2026-10-18.md): 21/36, 12 провалов, 2 частично, 1 конфликт. Это результаты описанных контуров проверки, а не обещание оценки жюри.

Проверены настоящие Excel организаторов и локальные THX-01, Ollama `gemma4:e4b`, Silero `v5_ru`, Faster-Whisper `small`. Полная HTTP-матрица использовала отдельную persistent mock-базу на каждый ID, шесть сценариев повторены с TTS/ASR. На ВМ проверены реальный SIP/RTP и переводы 101/104/102, а затем голосовые HTTP-диалоги с настоящей МИС на рабочем ядре. ВМ использует ранее явно настроенный NLU `hub`; локальная матрица — Ollama. Карточки и аудио в удалённый NLU не отправляются. Аудио, стенограммы и plaintext debug выключены.

`make check build` прошёл локально и на ВМ: Go race/vet/gofmt, Ruff, 44 Python-теста. Регрессионный датасет: **51/51**, с проверками фактического изменения визитов после каждого шага. Напоминание использует собственную вымышленную карточку: прежний runner мог выбрать последний визит другого пациента после неуспешной подготовки дубля.

Во внешней МИС использовался только вымышленный клиент №263. Выполнены ровно один POST визита №279 и один PATCH его отмены; конечный статус «Отменена» проверен. Другие визиты не менялись, новая карточка пациента не создавалась. За прогон — 13 запросов, 0 ответов 429, максимум 10 запросов в скользящую минуту по событиям ядра. Это наблюдение одного обычного диалога, не нагрузочное испытание.

Полный входящий loopback SIP-сценарий записи на ВМ занял **65,95 секунды** до ответа об успешной записи. Затем этот же тест отменил созданный визит. Включены синтез речи, RTP, ASR и обработка; человеческих пауз нет. Отдельно проверены реальные соединения тестовых SIP-аккаунтов: «соедините» → 101, «хочу умереть» → 104, зубная боль/отёк → 102. Соединение со штатным сотрудником и внешний Linphone этим прогоном не проверялись.

## Что исправлено

- Локальный перехват угрозы «хочу умереть», короткой просьбы о человеке и стоматологического R-09 во всех активных состояниях.
- Явный запрос чужой записи блокируется до чтения; доступ и принадлежность выбранного визита проверяются в контроллере. Местоимение в «перенесите её» после идентификации не меняет пациента.
- Ненайденная карточка требует перепроверки, затем регистратора; автоматическое создание по ошибке ASR исключено.
- Исправлены короткий вопрос о своей записи, субботний график, автоответчик, обращение по имени/отчеству и длина проверенных реплик.
- Квота МИС: интервал 6,1 секунды; GET после 429 может повториться один раз через Retry-After, если позволяет контекст. POST/PATCH не повторяются. При нехватке квоты диагностическое чтение возвращает 503 с Retry-After.

## Оставшиеся границы

- **T-12:** CSV требует отмену и создание заново, проектный контракт — PATCH того же ID. Код сохраняет утверждённый инвариант. Ожидание CSV оставлено без изменений.
- **T-16:** нет API персональной готовности анализов. Бот честно сообщает ограничение и переводит к регистратору. Общие сроки доступны; по уточнениям организаторов они достаточны для обязательного сценария, но полный личный статус из CSV не засчитан.
- **T-32:** проверен контракт неактивного врача; полный голосовой сценарий деактивации не выполнен. Общий справочник стенда не изменялся.

## Повторение

Из корня репозитория, с настроенным приватным `.env`, установленными моделями, работающим речевым сервисом с настоящей THX-01 и Ollama `gemma4:e4b`:

```bash
make check
AI_WORKER_URL=http://127.0.0.1:18000 make zer0days
AI_WORKER_URL=http://127.0.0.1:18000 make zer0days-voice
```

Адрес 18000 относится к отдельному локальному прогону; обычный worker слушает 8000. Эти команды проверяют mock и сохраняют отдельный результат; сами по себе T-28/T-29 не проходят. На подготовленной ВМ для SIP есть `make sip-check-vm`: он требует отсутствия активных звонков, временно использует отдельную mock-базу и в `finally` возвращает рабочую МИС.

Исходный CSV не изменён. Полный JSON, трассы и заполненная копия CSV находятся локально в `var/zer0days-final-fixed-20261019/`, первичные доказательства — в папках, перечисленных в JSON. Файлы результатов имеют права 0600, папки — 0700. Хеш проверенного локального бинарника сохранён в метаданных исходного HTTP-прогона. Проверка настоящего стенда выполнена отдельно на ВМ для одной заранее сверенной вымышленной карточки; скрипт не повторял операции с неизвестным исходом.
