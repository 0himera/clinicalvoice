# Исправления замечаний и аудитов, 18 октября 2026

Проверены замечания организаторов, оба предоставленных аудита и коммиты
`9e3593c`, `24143d7`. Часть прежних исправлений сохранена; новые исправления
не заменяют проверку реального звонка. Протокол запуска — в [приёмке](acceptance.md).

| Область | Результат проверки и изменение |
| --- | --- |
| Cat A: отрицания | Отрицание привязано к симптому; «не знаю, инфаркт», «нет сил, задыхаюсь», независимый маркер и отрицательный предикат «не могу дышать» сохраняют экстренный маршрут. Поддержаны обратный порядок слов, ё и постпозиционное «инфаркта нет». Cat B также учитывает отрицание. |
| Threat decider | Удалены неработающий hook, прежний API подавления угрозы моделью и тест, который якобы проверял вызов этого hook. Экстренный гейт локален. Метафора не может подавить независимый физический маркер. |
| ASR | Отмена ожидающей корутины не освобождает семафор до завершения native-потока. Faster-Whisper явно получает `num_workers=2`; ошибка инференса не превращается в пустую речь в методе transcribe. |
| TTS | Экземпляр возвращается в пул callback-ом завершения потока; один объект не размножается на несколько leases. Пул требует разных экземпляров. Регрессия отменяет первый запрос и пытается использовать модель вторым. |
| Decision | Реальные excerpt-запросы всегда исполняет THX-01, без регулярочного обхода по фамилиям. Отменённые запросы не накапливаются в очереди executor; уже начатый native-инференс сохраняет разрешение. Mock явно обозначен в ответе. |
| Barge-in | Порог согласован с минимумом принимаемой реплики: 5 × 32 мс. Двухкадровый шум не отменяет речь бота. Перед /turn проверяется актуальность ревизии ASR; очистка старой очереди сохранена. |
| AudioSocket | Ограничены чтение тела и writer.drain; дочерние задачи закрываются вместе со звонком. Сохранён отдельный последовательный VAD worker на звонок. Расчёт PCM-метрик также вынесен с event loop. Task удаляется гарантированным callback-ом; сетевое закрытие ограничено по времени. |
| Pending/uncertain | На старте удаляются holds исчезнувших сессий. Просроченный pending переходит в uncertain, сохраняя блокировку. Добавлены защищённый список claims и сверка с МИС; отсутствие совпадения не освобождает время. Сверка во время звонков не заменяет booked из устаревшего снимка. |
| Перенос | Отдельное удаление старого booked перед Resolve убрано: перемещение того же visit ID выполняется одной локальной транзакцией. Ошибка локальной фиксации не маскируется успешной речью. Settlement имеет отдельный ограниченный контекст после ответа МИС. |
| Очередь заявок | Исправлена регрессия последнего коммита: просроченный SENDING становится UNCERTAIN, а не PENDING. Неизвестный POST не повторяется. Техническая карточка защищена маркером неизвестного создания и поиском существующей. Дедлайн финального UPDATE начинается после ответа МИС. Есть список проблемных заявок без пациентского текста. |
| Авторизация | Оба HTTP-сервиса отклоняют пустой токен на защищённых маршрутах. Настоящий speech startup проверяет токены. Setup восстанавливает пустые секреты шаблона, сценарные серверы создают собственный токен и передают его клиенту. Документация больше не обещает необязательную авторизацию. |
| Удалённый NLU | Защита перенесена в клиент, работает и на первой реплике. Принимается закрытый словарь; имена, числовые/словесные даты, адреса и неизвестные слова требуют локального разбора. Идентификационные сущности удалённой модели не принимаются. Регрессионный HTTP transport проверяет отсутствие отправки приватной реплики. Это ограничивает recall удалённого fallback. |
| /turn и /interrupt | Новые реплики закрытого звонка дают 410. Прерывание проверяется при регистрации контекста; позднее сохранение менее важной заявки не перезаписывает экстренный результат. SQLite не задерживает экстренную речь: persistence выполняется отдельно с дедлайном. Не обещается откат уже выполненного изменения МИС. |
| Повторы turn ID | Кэш больше не теряет результат после 16 других реплик; максимум новых шагов ограничен 256. Конфликт текста даёт 409. После рестарта call ID неизвестен и получает 404, а не повторное выполнение FSM. Восстановление сессий не реализовано и не заявляется. |
| SQLite health | Исправлен query-only DSN. Liveness проверяет чтение, readiness — также доступность пула записи. Долгая write-транзакция даёт readiness 503 без ложного отказа liveness. |
| Обзвон | Сохранены heartbeat при репликах и добавлено продление активной сессии в janitor. Явный dial активного, завершённого, отложенного либо исчерпанного задания даёт ошибку вместо ложного «queued». Ошибки компенсирующего UPDATE возвращаются. |
| Квота МИС | Сохранены официальные 10 RPM. Фоновые работы не резервируют будущие токены перед ожидающим интерактивным запросом. Retry-After повторно проверяется после очереди; отложенные запросы не образуют burst. Неотправленная операция не считается неизвестной. |
| Два NLU | Ошибка или UNKNOWN первого ответа не отменяет второй провайдер. Убрана связь доступности Decision с наличием LLM при идентификации. В Decision добавлены диалоговые действия и корректная выбранная вероятность; русский классификационный вопрос проверен настоящей моделью. |
| SIP и протоколы | Диагностические скрипты читают сгенерированные секреты, стандартные пароли удалены из примеров. Повторный setup не меняет SIP-пароли. AMI формируется из проверенных полей; FastAGI использует единый проверяемый encoder. |
| Excel | Колонки сопоставляются по заголовкам и допустимым именам исходного файла, неизвестная схема отвергается. MatchDoctors не оставляет частично изменённый snapshot при ошибке. Сохранены предыдущие исправления пустых строк и времени 9:00. |
| Документация | README переписан без неподтверждённых задержек, ускорений, сертификации и абсолютной защиты. Требование Go соответствует go.mod (1.27). Исправлены коды сценариев, три непонимания, TTS default, API и Makefile. Добавлен gofmt check. |
| Ключ и стенограммы | Зануление входного среза сохранено как best effort: cipher держит рабочий ключ. CLI требует терминал либо явный -allow-stdout для экспорта. Python запрещает одновременную plaintext-отладку и encrypted transcripts; тексты ASR поступают в шифрующий sink Go через /interrupt. |
| Дополнительные мелочи | Воскресенье добавлено в детерминированный разбор предпочтений; короткое «лор» не ищется внутри постороннего слова. Decision response ограничен по размеру и не следует redirect. Из транспортных ошибок МИС удалён URL с пациентскими поисковыми параметрами. |

Не приняты опасные либо неприменимые рекомендации из аудитов:

- Поднять квоту до 10 RPS нельзя: в задании установлено 10 запросов в минуту.
- Возвращать неизвестный SENDING в PENDING или удалять uncertain по таймеру нельзя: это допускает дубликаты.
- Удаление raw-текста из экстренной диагностики не запрещает адрес и причину явно подтверждённой заявки на дом в МИС: это отдельное требование организаторов. Ограничение doctor ID относится к сопоставлению справочников, а не запрету передавать карточки и визиты в МИС.
- Фиксированный GMT+4 нужен по контракту стенда; смена часового пояса на время хоста была бы ошибкой.
- ValueError нормализатора на невозможной дате не является доказательством падения HTTP-сервиса: API обрабатывает такие ошибки. Невозможные даты не следует произносить как действительные.
- Удалить рабочий AES-ключ из памяти, продолжая шифрование тем же cipher, невозможно. Удалённые файлы также не следует описывать как гарантированно физически стёртые на любом накопителе.

Проверено: `make check`, `make build`, 51/51 текстовых сценариев с настоящими
локальными THX-01 и Ollama, mock-МИС и вымышленными пациентами. Датасет не
ослаблялся. На этапе исправления аудитов отдельно не перепроверялись реальный
ASR/TTS, SIP/RTP, внешний API стенда, нагрузочные и бизнес-показатели.
Последующий протокол развёртывания ВМ добавлен в [приёмку](acceptance.md),
повторяемый запуск — в [инструкцию ВМ](deployment.md). Native-инференс принудительно не
прерывается; неопределённые операции, не подтверждённые чтением МИС, требуют
проверки сотрудником.
