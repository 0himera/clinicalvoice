# AI Worker — Voice Bridge & Speech Engine

Микросервис голосовой обработки на базе **FastAPI**, **CUDA (PyTorch)**, **Faster-Whisper** и **Silero TTS v4**.

---

## Архитектура и возможности

1. **ASR (Распознавание речи):**
   * Модель: `faster-whisper` (`small` на CUDA float16).
   * Задержка: **60–140 мс** на фразу на NVIDIA RTX 3070.
   * Автоматический ресемплинг входящего аудио (8 кГц телефония, 24/48 кГц микрофон) к эталонным **16 000 Гц mono**.

2. **Нормализация текста (`src/normalizer.py`):**
   * Silero TTS v4 не имеет встроенного токенизатора для чисел и молча отбрасывает цифры.
   * Модуль автоматически переводит в словесную русскую форму:
     * Время с предлогами: `с 7:30 до 20:00` $\rightarrow$ `с семи тридцати до двадцати`
     * Даты со склонением: `15 апреля 1985 года` $\rightarrow$ `пятнадцатого апреля тысяча девятьсот восемьдесят пятого года`
     * Кабинеты, телефоны, символы: `кабинет № 210` $\rightarrow$ `кабинет номер двести десять`
     * Службы экстренной помощи: `103`, `112`, `122`

3. **TTS (Синтез речи):**
   * Модель: `snakers4/silero-models` (v4_ru, голос `kseniya` / `baya`).
   * Частота дискретизации: **24 000 Гц** (студийное естественное звучание).
   * Задержка генерации: **10–50 мс** на реплику.

4. **VAD (Детекция речи):**
   * Модель: `Silero VAD v5` для отсечения пауз и фонового шума.

---

## HTTP API

* `GET /health` — проверка состояния моделей и доступности GPU.
* `POST /asr` — передача `multipart/form-data` файла аудио (`file`), возвращает `{"text": "...", "latency_ms": 120}`.
* `POST /tts` — передача JSON `{"text": "...", "speaker": "kseniya"}`, возвращает поток `audio/wav` (24 кГц).

## Запуск сервиса

### С использованием `uv` (рекомендуется):
```bash
uv sync
uv run python main.py
```

### Напрямую через Python виртуальное окружение:
```bash
python main.py
```
По умолчанию сервис слушает на `http://0.0.0.0:8000`.
